Nota sobre o desenvolvimento

O desenvolvimento deste projeto também contou com o uso de ferramentas de Inteligência Artificial como apoio durante a implementação. A proposta inicial partiu de uma construção mais manual, porém, 
durante o desenvolvimento, percebi que a abordagem baseada em vibe coding permitiu chegar a uma interface visualmente mais agradável, organizada e adequada à proposta do trabalho.

A utilização da IA ocorreu como ferramenta de apoio à implementação e experimentação. A definição do conteúdo, das informações apresentadas, 
da estrutura solicitada pela atividade e a revisão do resultado final permaneceram sob minha responsabilidade.

O projeto foi posteriormente revisado e adaptado para atender aos requisitos da disciplina, mantendo HTML5, CSS3 e JavaScript como tecnologias principais.
